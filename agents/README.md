# Card-AI — команда AI-агентов

Версия: 0.1.0  
Назначение: подготовка коммерческих карточек товаров для маркетплейсов.

## Роли
1. Продюсер — принимает бриф, управляет этапами и собирает пакет.
2. Аналитик — изучает товар, аудиторию и конкурентов.
3. Арт-директор — задаёт визуальную концепцию и сценарий галереи.
4. AI-фотограф — готовит фотосцены и задания для генерации/съёмки.
5. Дизайнер — собирает инфографику и экспортирует изображения.
6. SEO-копирайтер — готовит заголовки, преимущества и описание.
7. Контролёр качества — проверяет достоверность и готовность к публикации.

## Как запускать без оплаты API
На первом этапе это команда специализированных ролей, исполняемых последовательно в ChatGPT. Это не семь независимо работающих серверных ботов. Такой режим не требует API-ключей и не создаёт расходов на API. Внешние облачные генераторы подключаются только после проверки их бесплатных условий.

## Конвейер
Бриф и исходники → анализ → концепция → фотоплан → тексты → дизайн → QA → экспорт.

Каждый этап должен оставлять артефакт в папке проекта: brief, research, concept, shotlist, copy, design, qa, exports.

## Жёсткие правила качества
- Не менять форму, цвет, пропорции и конструкцию товара.
- Не выдавать фото другого товара за исходный продукт.
- Не выдумывать размеры, материалы, комплектацию, гарантии и свойства.
- Lifestyle-сцены должны показывать правдоподобное использование.
- Текст на изображениях — короткий, крупный и без ошибок.
- Если факт не подтверждён исходниками, пометить его как требующий подтверждения.
- Не имитировать отзывы, рейтинги, сертификаты или результаты тестов.

## Первый пилот
Товар: выжиматель влажного корма для животных.  
Исходники: `product-cards/originals/`.  
Цель: коммерческая галерея из 6–8 изображений.  
Важное ограничение: исходный бежевый выжиматель должен оставаться узнаваемым и неизменным.
