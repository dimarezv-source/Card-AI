# Product Cards — рабочая зона

Эта папка предназначена для исходников и результатов генерации товарных карточек.

## Структура

- `originals/` — оригинальные фотографии товаров (не изменять).
- `references/` — примеры стиля и визуальные референсы.
- `descriptions/` — подтверждённые характеристики и тексты товаров.
- `prompts/` — задания для генерации и редактирования.
- `generated/` — готовые изображения и версии карточек.

## API и автоматизация

Описание API приёма фотографий, просмотра исходников и ведения каталога: [API.md](./API.md).

**Автоматический каталог через GitHub:** загружайте фото в `originals/<SKU>/`. После попадания изменений в `main` GitHub Actions автоматически соберёт `catalog/index.json` с именами, форматами, размерами и SHA-256 исходников. Дополнительные подтверждённые поля товара можно положить в `originals/<SKU>/product.json` (образец: [product.example.json](./catalog/product.example.json)). Инструкция: [originals/README.md](./originals/README.md).

## Рабочий процесс

1. Добавить исходные фотографии в `originals/`.
2. В этом чате написать название товара и пожелания.
3. Подготовить тексты, композицию и задания для внешних ИИ.
4. Сохранить готовые материалы в `generated/`.

## Важные правила

- Не менять форму, конструкцию, цвет, комплектацию и маркировку товара без прямого указания.
- Не придумывать характеристики, сертификаты и преимущества.
- Сохранять оригиналы отдельно от обработанных изображений.
- Использовать только инструменты с подтверждённым бесплатным экспортом; платные функции не подключать.
- Не размещать в публичном репозитории личные данные, ключи API, пароли и конфиденциальные документы.
