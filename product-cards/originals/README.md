# Исходные фотографии товаров

Загружайте оригиналы в отдельные папки по SKU или внутреннему ID товара:

`product-cards/originals/<SKU>/photo-01.jpg`

Поддерживаются JPG/JPEG, PNG и WebP. Для описания товара положите рядом файл `product.json` с подтверждёнными полями; пример приведён в `../catalog/product.example.json`.

**Важно:** репозиторий Card-AI сейчас публичный. Все файлы в этой папке будут доступны всем по ссылке. Не загружайте личные, клиентские или конфиденциальные изображения.
